## Stdlib modules

- [ ] **JSON module** — `Json parse:` / `Json stringify:` (examples.md M2). A `peg` grammar (`object`/`array`/`string`/`number`/`true`/`false`/`null`) lowering to birnam maps/vectors/strings/numbers/bool/nil; `stringify:` is the reverse over the `appendRef` formatter shape. Cleaner PEG fit than YAML (not whitespace-sensitive). Round-trips config + FFI payloads. *peg combinators, maps/vectors, `format:`.*
- [ ] **YAML module** — `Yaml parse:` (examples.md M1). A `peg` grammar for a **flat subset** (block mappings + block sequences + scalars; flow `[a, b]`/`{k: v}` as an add-on) lowering to birnam maps/vectors/strings/numbers. Real YAML is indentation-sensitive and not cleanly PEG-expressible — scope to one level of block structure (the 80% configs use) and note the limit. Pairs with example #4 (config reader). *peg combinators, maps/vectors/strings, `File read:`.*
  - Both follow the same shape as `lang.zig`'s grammar (build with `peg_seq`/`peg_choice`/`peg_star`/`peg_charset`/`peg_literal`/`peg_rule_ref`) and return native birnam data, so a parsed result drops straight into `at:`/`do:`/`collect:`. Decide host: a wrapped/first-party birnam unit vs a zig `peg`-module like `query`.

## Config / shell

- [ ] **Generalize module overrides** — promote the one-off `repl = "linenoise"` (`src/config.zig` + the birnam-REPL handoff in `shell.zig`) into a general `[module_overrides]` section where the user injects a preferred implementation for *any* overridable module, e.g. `[module_overrides]\nrepl = "linenoise"\njson = "jsmn"`. A module declares an override point (slot name); birnam loads the named impl in place of the default. Keep top-level `repl = "…"` working (alias into the new section). Per the DONE.md note, also accept overrides via an **env var** and a **command-line flag**, both taking a comma-separated `slot=impl` list — `BIRNAM_MODULE_OVERRIDES=repl=linenoise,json=jsmn` and `--overrides repl=linenoise,json=jsmn`. Precedence: argv > env > toml > default (last wins per slot). Touches `config.zig` (TOML subset parse — new table + a shared `slot=impl,…` list parser), `shell.zig` (merge the three sources, resolve + apply per slot — currently special-cased for repl), and override-point registration on the module side. See [[project_birnam_ergonomics]] and the wrapped-libs/linenoise conventions in DONE.md.
