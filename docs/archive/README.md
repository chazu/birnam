# Historical documentation

This directory preserves prior designs, rejected approaches, completed migrations
and dated investigations. It is not architectural authority or an active work
queue. Words such as "current," "required," "accepted," and "remaining" inside
an archived document refer to the period it records.

Start new work from [INVARIANTS.md](../../INVARIANTS.md), the
[current architecture](../../ARCHITECTURE.md), and the relevant current message or
format reference. Do not turn archived implementation mechanisms into new
requirements. Do not rewrite old failures or measurements to make them look like
evidence for a different implementation.

- [October 2026 runtime/documentation consolidation](2026-10-runtime-refactors/README.md)
  contains the relocated refactor logs and the record of what replaced their
  active guidance.
- `design/`, `guide/`, and `misc/` contain earlier archives. They remain historical
  even where an older document's own introduction calls it authoritative.

Measurement files remain at their recorded paths so existing evidence stays
identifiable. A historical result is useful only within its recorded scope.
