# Stackless S2 canonical byte fixtures

These files are frozen conformance evidence for
[Design 60I](../../../docs/design/60i-stackless-artifact-byte-grammar.md).
They are not compiler inputs, bootstrap inputs, or permission to infer a byte
grammar from an implementation. Ordinary builds must not regenerate them.

Run `python3 verify.py` from this directory for the independent structural,
semantic, mutation, truncation, length, and SHA-256 checks. The checker shares
no code with a production codec and never generates expected bytes. A plain
`shasum -a 256 -c SHA256SUMS` remains available for checksum-only verification.
Replacing a binary is a physical-format design change and requires an explicit
review of its annotated bytes and digest.

`python3 build-fixtures.py OUTPUT_DIRECTORY` is a manual reproduction aid. It
refuses to choose the committed directory implicitly; compare its output with
the frozen binaries deliberately. The independent `verify.py` does not import
that serializer. Malformed fixtures are intentionally not regenerated by the
canonical serializer.

The independent reader additionally derives these non-file-sized cases from
`artifact-selection-mixed.bin` and requires deterministic rejection before any
