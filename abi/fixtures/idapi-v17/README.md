# IdApi v17 native fixture

Independent C mirror of the 21-field, 168-byte arm64 macOS table. Native
initialization receives API, prior state, presence, import, export, vtable
enumeration, method observation, root registry GC settings and payload-layout pointers. The client checks
canonical runtime protocols and repeated initialization with the same borrowed
capabilities. Historical fixtures remain frozen. See design 81BL for the
extraction scope and validation status.

`storage_v1.h` keeps Storage v1's unchanged layout with the current IdApi include.
